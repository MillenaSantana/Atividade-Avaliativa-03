# Atividade Avaliativa 03 — Ordenação e Arquivos em C

Programa desenvolvido em linguagem C para trabalhar com algoritmos de ordenação e manipulação de arquivos.

## Funcionalidades

- Criar e gravar valores numéricos desordenados em um arquivo.
- Ler os dados armazenados.
- Escolher um algoritmo de ordenação.
- Salvar os valores ordenados em um novo arquivo.
- Alterar um valor e realizar uma nova ordenação.

## Algoritmos de Ordenação

- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

## Arquivos

- `dados.txt`: contém os valores numéricos de entrada.
- `ordenado.txt`: contém os valores ordenados.
- `programa_ordenacao_arquivos.c`: código-fonte do programa.

## Execução

O programa pode ser compilado e executado em um compilador C, como o GCC ou o OnlineGDB.

## Objetivo

Aplicar os conceitos de algoritmos de ordenação e manipulação de arquivos em C, reunindo as funcionalidades em um único programa.
